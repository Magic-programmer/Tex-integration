# Aspro.Cloud: ежедневный CSV

На сервере нужен один исполняемый скрипт. Скопируйте только:

```text
export_aspro.py    # API, преобразования и запись CSV
reports.json      # адрес аккаунта, поля, фильтры и маппинги
requirements.txt  # requests
README.md         # инструкция
```

`tests/`, `tools/`, `pyproject.toml`, `requirements-dev.txt`, примеры и окружение
нужны для разработки; на сервер их переносить не нужно.

## Установка и запуск

Debian Linux, Python 3.9+ с venv, системные сертификаты и tzdata.
Из каталога со скриптом:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python export_aspro.py --check-config
.venv/bin/python export_aspro.py
```

Ключ — в переменной `ASPRO_API_KEY` или приватном файле
`$HOME/.config/aspro-export/api-key` (владелец — пользователь запуска, права
600; каталог 700). Скрипт читает файл и помещает ключ в окружение процесса.
Иной путь задаётся через `ASPRO_KEY_FILE`. Ключ не передаётся в аргументах,
не хранится в reports.json и не выводится в журнал.

По умолчанию выход — `$HOME/.local/state/aspro-export/exported/current/`:
`Контрагенты.csv`, `Сделки.csv`, `Задачи.csv`, `База ГПУ.csv`, `manifest.json`.
Другой каталог: `--output /фактический/каталог`. Другой аккаунт — base_url
в reports.json или ASPRO_BASE_URL. Выбор одного отчёта: `--report Задачи`;
используйте отдельный каталог вывода для таких проверок.

Исторические подписи, недоступные через API, хранятся отдельно и приватно:
`$HOME/.config/aspro-export/user-labels.json` и `account-labels.json`, объекты
ID → подпись, права 600. Перенесите их отдельно при установке. Пути меняются
через ASPRO_USER_LABELS_FILE и ASPRO_ACCOUNT_LABELS_FILE. Живые подписи API
имеют приоритет. Без локального имени пользователя сохраняется ID;
неразрешённая ссылка на агента останавливает отчёт.

## Поведение

Выгрузка полная: GET, страницы по 100 записей, проверка пагинации и ID,
повтор временных ошибок/429/5xx. TLS остаётся включённым. Секреты и значения
CRM не журналируются. Код выхода: 0 — локальная публикация, 1 — ошибка.
Пауза между запросами: ASPRO_REQUEST_INTERVAL, по умолчанию 1,1 секунды.

CSV: UTF-8 с BOM, русские заголовки; запятая у первых трёх отчётов,
точка с запятой у ГПУ, как в примерах. Файлы проверяются и публикуются
целым набором заменой current; частичный отчёт не становится рабочим.
Предыдущий комплект сохраняется. Одновременные запуски блокируются flock.
E-mail сохраняет исходный текст; удаляются BOM, пустые элементы и точные дубли.
Особенности ручного CSV, включая ID подзадач, настроены в reports.json.

## Cron и Windows

Для 01:00 по Москве сервер должен работать в Europe/Moscow (`timedatectl`).
В crontab пользователя сервиса, с фактическими путями:

```cron
0 1 * * * /путь/к/.venv/bin/python /путь/к/export_aspro.py >> /путь/к/export.log 2>&1
```

Настройте права и ротацию журнала. Cron пока не включён. Доставка на Windows
ещё не реализована: путь, сеть/VPN, протокол SMB3/SFTP и уведомления не согласованы.
Локальный успех не означает доставку. Новый ключ даёт доступ к четвёртому отчёту «База ГПУ»: GET
customlists/lists/3/items. Пагинация page/limit, count/total_result и
43 определения пользовательских полей через customfields=1 подтверждены
успешными ответами. Четвёртый отчёт теперь входит в обычный запуск.

## Разработка

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Для локального повторного сравнения без сетевых запросов:

```bash
.venv/bin/python tools/full_check.py \
  --cache "$HOME/.local/state/aspro-export/full-check-20261013" \
  --output "$HOME/.local/state/aspro-export/full-check-output" --examples ../examples
```

Добавьте --download и новый каталог кэша для новой загрузки. Страницы и
приватные отличия остаются вне Git. Последняя полная проверка: 24 131
контрагент, 18 532 сделки, 60 335 задач; все ID совпали. Сделки и задачи
совпали по всем значениям. Приняты 72 различия отображения e-mail и две более
новые даты изменения контрагентов. Исторические подписи восстановлены из
примеров, а не независимо подтверждены API. Транзакционная одновременность
всех страниц API и побайтовая идентичность ручному CSV не гарантируются.


## Проверка ГПУ

Сохранены все 2 613 строк и сопоставлены 44 столбца. Имена/типы 43 полей cf_*
подтверждены API через customfields=1; дата создания — стандартное поле.
Пример не содержит ID. Строки сопоставлены в порядке ID по возрастанию с
проверкой трёх независимых полей: № пп, адрес и мощность. При расхождении
числа строк или этих опор инструмент сравнения прекращает сопоставление.

Контрагент, владелец и сервисная компания — ссылки на crm/account, сделка —
на crm/lead. 18 недоступных через get карточек дополнены однозначными именами
из примера в приватном account-labels.json. Подписи четырёх select.single и
ссылок «Заказ ТЕХ» восстановлены по устойчивым соответствиям ID в примере.
В reports.json источник этих соответствий указан явно. Отдельный API
customfields/fields/list пока закрыт новому ключу; получить актуальные наборы
вариантов автоматически не удалось. Целевая модель «Заказ ТЕХ» из доступных
определений model.any не раскрывается. Новый неизвестный ID останавливает
экспорт вместо выдуманного значения. Переименования вариантов следует
проверять по свежему примеру либо после открытия API определений полей.

Формат часа в дате создания повторяет пример, без ведущего нуля.
Остальные 570 отличий строкового представления относятся к изменениям Excel:
403 округления в научную запись, 129 группировок цифр/пробелов, 18 пробелов по
краям, 6 преобразований числового представления, 13 комментариев в #ИМЯ?
и один код двигателя, превращённый в дату. В нашем CSV исходные номера,
комментарии и коды сохранены без округления/вычисления. Для просмотра в Excel
импортируйте серийные номера, коды и комментарии как текст.

Результат — База ГПУ_API.csv в рабочей папке. Частные ответы API, сопоставление
и полные значения отличий сохранены локально вне Git. Производственный путь
записи CSV проверен на этом полном кэше; хеш файла совпал с результатом
инструмента сравнения. Перегенерация старых задач может менять флаг
просроченности открытой задачи по мере наступления её крайнего срока.
