# Экспорт Aspro.Cloud в CSV

Независимый проект на Python 3: `requests` для API, стандартный `csv` для
отчётов, `logging` для диагностики, `pytest` для тестов. Обычный запуск создаёт
полные отчёты «Контрагенты», «Сделки», «Задачи». Столбцы и их порядок задаёт
[config/reports.json](config/reports.json); описание полей —
[docs/mapping.md](docs/mapping.md).

CSV: UTF-8 с BOM, запятая, LF. Полные файлы проверены по ID с клиентскими
примерами; результаты и ограничения — [docs/validation.md](docs/validation.md).
Локальный экспорт готов. Доставка на Windows Server ещё не настроена:
путь, доступность сети/VPN, протокол и уведомления не согласованы.
«База ГПУ» остаётся отдельной незавершённой работой.

## Установка и запуск

Подтверждена среда Debian Linux, время запуска 01:00 по Москве. Нужны
Python 3.9+, venv, системные сертификаты и tzdata. Точная версия Debian пока
не сообщена. Из каталога проекта:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Ключ передаётся через `ASPRO_API_KEY`. Для регулярного запуска
`bin/run-export.sh` читает его из `$HOME/.config/aspro-export/api-key` и
помещает в окружение Python. Файл содержит только ключ; владелец — пользователь
запуска, права файла 600, каталога 700. Путь меняется через `ASPRO_KEY_FILE`.
Не передавайте ключ в командной строке или в конфигурации отчётов.

```bash
.venv/bin/python -m aspro_export --check-config \
  --output "$HOME/.local/state/aspro-export/exported"

ASPRO_BASE_URL=https://gktex.aspro.cloud \
  bash bin/run-export.sh --output "$HOME/.local/state/aspro-export/exported"
```

Выход: `exported/current/Контрагенты.csv`, `Сделки.csv`, `Задачи.csv` и
`manifest.json` с числом строк и SHA-256. Выбранный комплект заменяет весь
`current`. Для проверки отдельного отчёта используйте отдельный каталог
вывода и `--report Контрагенты`, `--report Сделки` или `--report Задачи`.

## Приватные справочники

Недоступные через API исторические имена восстановлены из однозначных
связей в примерах. Они хранятся вне репозитория:

- `$HOME/.config/aspro-export/user-labels.json`: объект ID → имя пользователя;
- `$HOME/.config/aspro-export/account-labels.json`: объект ID → название агента.

Права файлов — 600. При переносе на сервер передайте их отдельно. Скрипт
запуска подключает существующие файлы автоматически; для других путей
используйте `ASPRO_USER_LABELS_FILE` и `ASPRO_ACCOUNT_LABELS_FILE`.
Живые подписи API имеют приоритет. При недоступном имени пользователя без
локальной подписи сохраняется ID. Недоступная ссылка на агента без подписи
останавливает отчёт. Частные коррекции e-mail не используются.

## Поведение и диагностика

Клиент выполняет только разрешённые GET, проверяет TLS и не следует
перенаправлениям. Пагинация по 100 записей проверяет счётчики, номера страниц
и повторные ID. Ошибки API/структуры останавливают отчёт; HTTP 429/5xx,
тайм-ауты, обрывы соединения и TLS EOF повторяются до четырёх попыток с
учётом Retry-After. По умолчанию пауза 1,1 секунды; настройка —
`ASPRO_REQUEST_INTERVAL`. Проверка сертификатов остаётся включённой.

CSV сначала записываются во временный каталог и повторно читаются для
проверки. Только завершённый комплект публикуется заменой ссылки `current`;
предыдущая версия сохраняется для восстановления. Запуски блокируются flock.
Читатель нескольких файлов должен один раз разрешить `current` и читать
весь комплект из полученного каталога.

Код выхода 0 — локальная публикация завершена, 1 — ошибка. Журналы содержат
этапы и счётчики без ключей, URL с параметрами и значений CRM. При ошибке:

- HTTP 401/403, application error: проверьте ключ и доступ к нужному модулю.
- Ошибка TLS: проверьте системные сертификаты, сеть и время.
- Неполная пагинация или изменение числа строк: повторите запуск в спокойный период.
- Неразрешённая связь: проверьте права и приватные справочники.
- Ошибка файла: проверьте права и свободное место.
- Another export is running: дождитесь предыдущего запуска.

API не предоставляет подтверждённого транзакционного снимка. Изменения
значений между страницами могут остаться незамеченными при стабильном числе
строк. Все данные, снимки, примеры и секреты исключены из Git.

## Полная проверка и локальное повторение

Один скрипт сохраняет страницы API, справочники и сравнивает CSV с примерами:

```bash
.venv/bin/python tools/full_check.py --download \
  --cache "$HOME/.local/state/aspro-export/full-check-new" \
  --output "$HOME/.local/state/aspro-export/full-check-output" \
  --examples ../examples
```

Повторный запуск продолжает ту же выборку из сохранённых страниц.
При изменении параметров запросов используйте новый каталог кэша.
Без `--download` все преобразования и сравнение выполняются локально.
Для ранее загруженного полного кэша укажите
`$HOME/.local/state/aspro-export/full-check-20261013`.

`comparison.json` содержит агрегаты; `differences.json` и списки ID содержат
приватные данные и остаются в каталоге кэша. Успех скрипта означает создание
валидных CSV, а не отсутствие отличий от примера. Значения сравниваются по ID;
порядок строк и одновременность снимков не гарантируются.

## Расписание и оставшиеся работы

Для cron сначала проверьте `timedatectl`: сервер должен работать в
Europe/Moscow. Пример crontab отдельного пользователя сервиса, с фактическими
путями установки, вывода и журнала:

```cron
SHELL=/bin/bash
ASPRO_BASE_URL=https://gktex.aspro.cloud
0 1 * * * /bin/bash /путь/к/aspro-cloud-export/bin/run-export.sh --output /путь/к/выводу >> /путь/к/журналу/export.log 2>&1
```

Cron пока не включён. Создайте приватный каталог журналов и ротацию.
Для передачи на Windows требуется согласовать SMB3 либо SFTP с проверкой
сервера, отдельную учётную запись и публикацию файлов под временными именами
с проверкой хешей и последующей заменой. Локальный успех не означает доставку.

Для «Базы ГПУ» заказчиком предоставлен GET
`/api/v1/module/customlists/lists/3/items`. Последний запрос вернул ошибку 22
доступа ключа к модулю. Необходимо подтвердить права, получить успешный ответ,
схему полей и пагинацию. Столбцы сохранены в
[config/pending-gpu.json](config/pending-gpu.json); эта конфигурация явно
блокируется до подтверждения маппингов и не входит в обычный запуск.
