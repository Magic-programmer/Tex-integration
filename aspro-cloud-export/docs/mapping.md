# Маппинг отчётов

Методы имеют префикс `/api/v1/module/`; авторизация — query-параметр
`api_key` из окружения. [Официальная документация](https://aspro.cloud/api/)
описывает list/get, фильтры, customfields=1 и пагинацию page/limit (максимум 100).
Поля и подписи дополнительно проверены на доступных данных аккаунта.

Конфигурация — единственный источник заголовков и правил. Ниже её текущее содержание.

## Контрагенты

GET `crm/account/list`. Параметры: `{"order_by[asc][]": "id"}`.

| Столбец | Поле API | Преобразование |
|---|---|---|
| ИНН | `VAT` | text  |
| Название | `name` | text  |
| Категория | `account_category_id` | lookup → crm/account_category/list → name |
| Сайт | `web` | text  |
| E-mail | `id` | lookup → crm/emails/list → email |
| Город (Адрес регистрации) | `billing_city` | text  |
| Ответственный | `owner_id` | lookup → core/user/list → name |
| ID | `id` | text  |
| Дата создания | `created_date` | datetime  |
| Дата изменения | `updated_date` | datetime  |

## Задачи

GET `task/tasks/list`. Параметры: `{"order_by[asc][]": "id", "filter[type]": "0", "filter[archive_status]": "0"}`.

| Столбец | Поле API | Преобразование |
|---|---|---|
| ID | `id` | task_id  |
| Название | `name` | text  |
| Статус | `status` | enum {"1": "Не выполняется", "3": "В работе", "4": "Ожидает контроля", "5": "Завершена"} |
| Постановщик | `owner_id` | lookup → core/user/list → name |
| Ответственный | `responsible_id` | lookup → core/user/list → name |
| Дата создания | `created_date` | datetime  |
| Крайний срок | `deadline` | datetime  |
| Завершена | `closed_date` | datetime  |

| Просроченность | `deadline` | overdue_flag  |
| Проект | `model_id` | project → st/projects/list → name |

## Общие правила и ограничения

- Даты: `ДД.ММ.ГГГГ`, время до минут; нулевые даты API — пусто.
  Явная зона переводится в Europe/Moscow; даты без зоны не сдвигаются.
- Деньги: пробел между тысячами, две десятичные цифры, суффикс ` p.`.
- E-mail: crm/emails/list, группировка по account_id и порядок по ID;
  точные дубли/пустые элементы/BOM удаляются, регистр и текст сохраняются.
- Компания сделки: только контрагент type=1. «Агент» ссылается на
  crm/account и может разрешаться дополнительным get/{id}.
- Недоступные исторические подписи дополняются приватными справочниками.
  Для нулевых ссылок Robot применяется лишь к подтверждённым ID записей.
- Задачи: type=0, archive_status=0; ID подзадачи имеет «— » за каждый
  уровень parent_id. Циклическая иерархия считается ошибкой.
- Просроченность — восстановленный флаг closed_date > deadline с точностью
  до секунд; у незакрытой задачи используется текущее время Москвы.
  Это представление экспорта, отдельного поля API не обнаружено.
- У ряда названий и связанных подписей убираются пробелы по краям/NBSP.
  У названия задачи и компании сделки непарная кавычка после HTML-декодирования
  даёт пустое отображение, апостроф — &#039;, как в ручном CSV.
  Это может скрывать непустой текст; исходный API-снимок сохранён.
- «Дела» — пустая колонка по всем 18 532 строкам примера; это не подтверждение
  отсутствия связанных дел в CRM и не вычисляемое количество.
