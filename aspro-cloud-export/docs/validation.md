Полные ответы API сохранены локально вне Git. Клиентские примеры в examples
также остаются локальными. Совпали все ID, заголовки и число строк трёх отчётов.

|---|---:|---:|---|

| Сделки | 18 532 | 333 576 | 0 |
| Задачи | 60 335 | 724 020 | 0 |

Даты в двух контрагентах: API 13.10.2026 00:12, пример 12.10.2026 18:20.
Заказчик принял их как обновление после сохранения примера.
Для e-mail согласована различимость вместо точного повторения ручной
нормализации. Адреса не исправляются догадками, отдельные 75 соответствий
исходной строки ручному CSV удалены из логики. Некорректные исходные адреса
могут оставаться некорректными; это не считается ошибкой формирования CSV.

API вернул 64 дополнительные архивные задачи; после archive_status=0 состав
совпадает с примером. 2 206 подзадач в ручном CSV имеют ID с префиксом «— »;
уровни вложенности подтверждены через parent_id.

Недоступные исторические подписи пользователей и трёх агентов восстановлены
из однозначных ссылок в примере, приватно. Это дополнительная информация из
самого эталона, а не независимая проверка справочника API. Для пяти других
агентов, отсутствующих в account/list, успешен отдельный GET.

Автоматические тесты используют синтетические данные. Покрыты пагинация,
повторы, ошибки API/TLS, справочники, преобразования, иерархия подзадач,
очистка списка e-mail, CSV, публикация целого набора и повторное использование
локальных страниц. Запуск: `.venv/bin/python -m pytest -q`.

Проверка значений идёт по ID, порядок строк и побайтовая идентичность не
гарантируются. Данные загружались последовательными запросами; API не даёт
подтверждённой транзакционной фиксации снимка. Проверены стабильность числа
строк, уникальность ID, структуры CSV и хеши опубликованных файлов.
